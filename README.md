# Basic Data Validation – Employee Data

## 📌 Project Overview

This project is a simple Excel-based **Employee Data Validation** sheet created to improve data accuracy and reduce incorrect entries.

The sheet contains employee information with dropdowns and validation rules.

## 🎯 Objective

- Improve spreadsheet data quality
- Prevent invalid data entry
- Make data entry easier using dropdowns
- Maintain consistent employee information

## 🛠️ Tools Used

- Microsoft Excel

## 📊 Dataset

The sheet contains the following fields:

- Employee ID
- Name
- Department
- Gender
- Age
- Salary
- Status

## ✅ Data Validation Rules

- **Department:** IT, HR, Finance, Marketing, Sales
- **Gender:** Male, Female
- **Status:** Active, Inactive
- **Age:** 18 to 60 years
- **Salary:** Minimum ₹10,000

## 📂 File Included

`Basic_Data_Validation_Employee_Data.xlsx`

## 💡 Key Learning

Through this project, I learned how to use **Data Validation, Dropdown Lists, Error Alerts, and basic Excel formatting** to maintain clean and accurate data.
